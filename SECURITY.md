# Security

## Reporting

Report vulnerabilities to **hi@x402r.org**. Include steps to reproduce and expected vs. actual behavior.

## Scope

This policy covers the SDK code in this repository. Smart contracts in [x402r-contracts](https://github.com/BackTrackCo/x402r-contracts) have **not been audited**.

## Status

x402r is not production-ready. Do not use it to handle real funds.
